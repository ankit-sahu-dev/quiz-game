# 🧠 Python Quiz Game

A beginner-friendly quiz game built using Python.

## Features
- 10 general knowledge questions
- Automatic answer checking
- Case-insensitive answer comparison
- Score tracking
- Final percentage calculation
- Performance feedback

## Concepts Used
- Dictionaries
- For loops
- If-elif-else
- User input
- String methods (`lower()`)
- Counters
- `len()` and `round()`
- F-strings

## How to Run

```bash
python main.py
```

## Project Goal

Built to improve my Python fundamentals through hands-on project development.
